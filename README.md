# AIRPiano supplementary demonstrations

This branch contains the static demo website for AIRPiano: Piano Score Following with Tabletop Hand Gestures.

The website includes two live performances with original-recording and camera/MIDI-replay views, followed by eight evaluation examples. Only anonymous participant IDs are used.

The complete website is in `docs/`. It requires no build step. GitHub Pages uses the `demo-review` branch and `/docs` folder.
